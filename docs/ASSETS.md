# Assets: what is in the repository and how the pictures are made

## In the repository

| Path | What | License |
|---|---|---|
| `public/figures/*.webp` | the anime figures: a person seen from behind on a sun lounger, cloud, flying carpet, drone, hot air balloon, swing, sailing boat, whale, swan float or surfboard; transparent background | generated for this project (see below) |
| `public/resorts/<name>.webp` | the anime map panoramas, sky cut out (alpha) | generated for this project |
| `public/resorts/<name>-card.jpg` | square card pictures of the maps | generated for this project |
| `public/mountains/<kind>-<far/mid/near>.webp` | far mountain strips (blue, snow, rock, forest, green) for `scenery.mountains` | generated by the author earlier; the sky was keyed out |
| `public/maps/*.json` | the six built-in maps (Maldives, Hawaii, Bali, Bora Bora, Thai beach, Ha Long Bay) | the author's own |
| `public/maps/added/` | maps you add in the app (json + card jpg) | yours |
| `public/sounds/` | wind, crickets, forest recordings | CC0 (OpenGameArt, see `CREDITS.txt`) |
| `public/sky/starmap.jpg` | NASA star map | public domain |
| `public/sky/moon.jpg` | the anime moon: a full moon seen straight on, its disc filling the picture | generated for this project (Krea 2 Turbo) |
| `public/sky/day`, `night`, `aurora` | anime sky pictures (7 each) picked at random at every dusk and dawn; the aurora ones are used by maps whose `sky.nightPhotos` is `aurora` | generated for this project |

No third-party photograph or 3D model is bundled.

## Music

The default track is a YouTube playlist set in `src/config.ts` (`DEFAULT_TRACK`). In the settings you can use a URL, a local folder or a playlist file instead. The equalizer only works for file and URL music; YouTube audio cannot be routed through Web Audio.

## How the pictures are made

Everything is made on the author's PC with a local ComfyUI (`http://127.0.0.1:8188`); the scripts are in `scripts/figures/` (see its README) and are run from a working folder outside the project. The style is anime (not photo-real): the scenery and the figure must look like one picture, and the resort must make people want to go.

### A figure (a person on a new seat)

1. `1-gen-figure.mjs`: Krea 2 Turbo draws the figure seen from behind on a flat green background. Edit `SCENES` for a new seat.
2. `2-remove-shadow.mjs`: Qwen Image Edit (2511, lightning, 4 steps) removes the cast shadow and flattens the green. Putting "no shadow" in the prompt does not work with the Turbo models (cfg 1, no negative prompt).
3. `3-cut-figure.mjs`: the ComfyUI-RMBG `BiRefNetRMBG` node (BiRefNet-matting) gives a real alpha matte. Crop to the subject, make it square, save a 768 px WebP in `public/figures`. Keep figures free of baked shadows: the app tints the picture by the time of day.

### A sky picture

Tall (896x1600) anime skies from Krea 2 Turbo, sky only, no sun, no moon, no ground. They follow the earlier photo-like set: each of the old pictures was analyzed (cloud type, colors, light) and rewritten as an anime prompt in `1-gen-sky.mjs`. VideoStudioOM's QwenVL "describe image" module can do the analysis automatically (`scripts/figures/describe.mjs`; it needs about 2 minutes per picture on this PC, so the prompts were written from the pictures directly). Day: scattered cumulus, big billowing clouds, cirrus streaks, a cumulus tower, peach sunset clouds, violet dusk clouds, a twilight gradient. Night: milky way and purple, teal, turquoise, red and yellow nebulae, moonlit clouds. Aurora: seven different curtains and ribbons.

### A map picture

1. `1-gen-panorama.mjs`: Krea 2 Turbo, 1792x768, an anime beach with palm trees framing the sides, sparkling water and flowers; buildings tiny and far away, a clear simple sky at the top.
2. `2-sky-to-magenta.mjs`: Qwen Image Edit paints the whole sky (and the gaps between the leaves) flat magenta. Magenta, not green, because the scenery is full of green leaves.
3. `3-cut-sky.py`: turns the magenta into transparency with a soft matte, so the palm leaves stay clean. Copy the WebP to `public/resorts/<name>.webp`, make a square crop `<name>-card.jpg`, and add `public/maps/<name>.json` (see `docs/spec.md`; `scenery.horizon` is the sea line as a fraction of the height from the top). Add the id to `BUILTIN_MAPS` in `src/main.ts` and to the list in `test/spec.test.mjs`.
