# Paradise

> Working directory: `E:\Claude\Paradise`

## Project Overview

A floating, stationary scene: a picture of a person seen from behind (a figure on a sun lounger, a cloud, a flying carpet, a drone, ...) in front of a misty resort panorama with the sky cut out, over a sea of clouds. Voyager's UI, time cycle, music, settings, maps, persistence and authoring flow are retained; the 3D character and the walking are gone.

## Tech Stack

TypeScript, Vite, Three.js, Capacitor, Electron, and Node.js.

## Commands

```bash
npm run dev
npm run build
npm test
```
